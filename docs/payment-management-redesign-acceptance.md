# 收款管理工作流重设计验收记录

日期：2026-08-04

## 实施范围

- 新增 `/payments/collect`、`/payments/detail/:id?`、`/payments/reviews` 三个真实页面与共享顶部导航；旧 `/payments` 自动跳转并保留查询参数。
- 收款登记支持合同与账期选择、连续账期限制、超级管理员人工分配原因、优惠／减免原子提交、JPG／PNG／WebP 凭证、预收款与金额摘要。
- 收款详情支持票据／房号／租户／日期查询，展示分配、优惠、凭证、操作痕迹，并提供打印、更正、退款及作废入口。
- 退款／作废确认支持统一队列、筛选、影响预览、逐条优惠撤销或保留决定、确认和驳回。
- 后端补齐收款凭证、分配顺序和来源、退款优惠决定、收款更正、统一审核查询及角色强制校验。
- 数据库 migration 使用兼容默认值回填历史分配顺序，不改写历史金额、票据或业务记录。

## 手工验收建议

1. 以管理员登录，进入“收款管理 → 收款登记”，选择有未结账单的合同。
2. 确认不能跳过最早账期；填写金额并观察右侧预收款计算。
3. 可选上传一张 JPG／PNG／WebP 测试凭证，提交后确认自动进入新票据详情。
4. 以超级管理员确认优惠；检查临时凭证转为正式票据。
5. 提交一笔部分退款，确认默认撤销关联优惠；改为保留时检查必须填写原因。
6. 提交作废申请并确认，检查原收款、票据和操作痕迹仍保留且状态为已作废。
