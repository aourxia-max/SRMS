# 合同编号格式验收记录

## 已确认规则

- 新建合同编号由后端自动生成，格式为：`HT+合同开始日期+全局序号 | 楼栋房号 | 住户姓名`。
- 示例：`HT202608050001 | 2栋301 | 李四`。
- 序号使用合同自增 ID 作为全局递增序号，首个正常合同显示为 `0001`，超过四位时保留完整数字。
- 主承租人姓名为空时显示“未登记住户”；房号和姓名中的分隔符会被清理，避免破坏编号结构。
- 编号最长按数据库现有 `contract_no VARCHAR(40)` 保存；超长姓名会在末尾截断。
- 合同账单继续使用 `${合同编号}-B001`、`${合同编号}-B002` 等编号。
- 历史合同和历史账单不回写、不重编号。
- 前端创建合同页面不再允许手工输入合同编号，保存后由系统返回完整编号。

## 本次修改

- 后端新增 `backend/src/contracts/contract-number.ts` 生成器。
- 固定月租和阶梯合同创建事务均先写入临时唯一编号，取得自增 ID 后更新为最终编号，再生成账单和房态历史。
- 创建 DTO 禁止客户端提交 `contractNo`；启用全局白名单校验时会返回校验错误。
- 前端合同表单改为“保存后由系统自动生成”。

## 手工验收步骤

1. 打开合同管理，新增固定月租或阶梯合同。
2. 确认页面没有可编辑的合同编号输入框。
3. 保存后，在合同列表中确认编号类似 `HT202608050001 | 2栋301 | 李四`。
4. 查看该合同账单，确认账单编号以合同编号开头并追加 `-B001`。
5. 使用已有历史合同，确认历史编号保持不变。
