# 房源 360°详情页设计

## 目标

从驾驶舱楼栋房态图点击房间，进入只读房源详情页，在一个页面了解房屋现状、合同、业主/租户、历史和经授权的财务收款信息。

## 页面与交互

- 路由为 `/properties/:id`，驾驶舱房间格传入房源 ID。
- 页头显示完整房号、楼栋、楼层、当前房态、状态变更时间和风险标签；操作仅包含返回、前往房源管理、合同管理和收款登记。
- 首屏显示房屋现状与业主资料；合同与租户显示当前合同，若无当前合同显示最近一份合同。
- 历史信息默认折叠，包含房态变更与历史合同。
- 无合同、无租户、无收款时使用明确空状态。

## 权限与数据

- 所有角色需登录才可访问；后端通过 `GET /api/properties/rooms/:id/detail` 返回详情。
- 业主和合同/租户基础资料沿用既有房源、合同、租户访问范围。
- 账单汇总、收款、预收款与退款等财务明细仅在超级管理员响应中返回；管理员、游客响应中不包含 `financial` 字段。
- 详情页无直接修改、删除、确认收款或审批动作，不绕过既有业务流程。

## 风险提示

- 当前合同存在逾期未收账单：显示“有逾期账单”。
- 当前合同结束日期在未来 30 天内：显示“合同即将到期”。
- 当前房态为维修中：显示“维修中”。
- 没有以上条件时显示“当前无待办”。
