# 驾驶舱本月租金收缴概览设计

## 目标

将驾驶舱原“租金趋势”替换为更直观的“本月租金收缴概览”。

## 统计口径

- 使用冻结的账期经营口径：账单的 `periodStart` 落在当前自然月。
- 租金净应收、有效实收、未收与收租率完全复用财务中心的 `FinanceService.rentCollection()` 计算。
- 收租率为有效实收 ÷ 租金净应收；净应收为零时不显示百分比。
- 押金、预收款、提成、未确认优惠和现金流不参与该概览。

## 界面

- 标题为“本月租金收缴概览”，副标题说明为账期经营口径。
- 展示本月应收、已收、未收、逾期欠租四个金额指标。
- 展示收缴率和中文状态文案：无应收、已收齐、待跟进、存在逾期。
- 采用蓝色信息卡、绿色收缴进度条和红色逾期提示；点击可进入财务中心。

## 边界

- 本次不做历史折线图，也不改变财务中心报表或现有催租/欠租待办。
- 后端仅在驾驶舱响应增加只读的 `rentCollectionOverview` 字段。
