# 驾驶舱楼栋房态图楼栋筛选设计

## 目标

在驾驶舱“楼栋房态图”卡片内提供独立的楼栋筛选，不改变驾驶舱全局经营指标。

## 交互

- 卡片工具栏新增“全部楼栋”下拉框，选项来自现有楼栋接口。
- 选择楼栋或房态后，仅重新请求房态图数据并更新房间格、图例及数量。
- 未选择楼栋时展示全部楼栋；清空选择恢复全部楼栋。
- 页面顶部已有的全局楼栋筛选保持现状，其作用范围不作改变。

## 实现边界

- 使用现有 `GET /api/dashboard?buildingId=&statuses=` 和 `GET /api/properties/buildings`，不修改数据库、权限或后端接口。
- 页面保持一份全局驾驶舱数据，另保存一份房态图数据，避免卡片筛选改变催租、欠租和合同到期指标。
- 不新增依赖；以前端构建和本机登录后的界面操作验证。
