# SRMS 正式部署设计

## 目标

将 SRMS 部署到已备案的腾讯云广州轻量应用服务器，正式入口为 `www.hetfw.cn`，根域名 `hetfw.cn` 永久跳转至 `www.hetfw.cn`。

## 架构

- Caddy 是唯一公网入口，监听 80 与 443，自动申请并续期 HTTPS 证书。
- 前端、NestJS API 与 MySQL 均由 Docker Compose 管理。
- MySQL 与 API 仅位于 Docker 内部网络，不映射公网端口。
- Caddy 将网页请求转发给前端服务，并将 `/api/*` 转发给 API 服务。
- 数据库、上传文件与备份分别使用具名卷持久化；服务异常后自动重启。

## 域名与备案

- `www.hetfw.cn` 是唯一正式入口；`hetfw.cn` 重定向到它。
- 网页底部展示备案号 `琼ICP备2026011136号-1`，链接至工信部备案查询站。
- 系统 UI 继续使用 SRMS 产品名称；备案资料中的服务名称不作为产品标题替换。
- 服务开通后，用户需在法定期限内完成公安联网备案。

## 安全与配置

- 生产密钥、数据库密码、初始管理员密码只保存在服务器的未跟踪环境文件中，不提交 GitHub。
- 服务器防火墙仅允许 22、80、443；MySQL 和 API 不直接暴露公网。
- 服务器部署使用本机保存且 Git 忽略的 SSH 私钥。
- 初始管理员仅在生产数据库没有用户时创建。

## 验证

1. Docker 服务均为健康状态。
2. `https://www.hetfw.cn` 可访问，`https://hetfw.cn` 自动跳转。
3. HTTPS 证书有效，HTTP 自动升级。
4. 登录与当前会话接口可用。
5. 生产数据库、上传文件和备份卷均存在。
6. 后端测试、接口测试、构建和 Lint 在发布前通过。

## 非范围

- 不更改已冻结的业务金额、权限、状态、数据结构或业务流程。
- 不新增业务功能。
- 不将数据库端口公开到互联网。
