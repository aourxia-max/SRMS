# 收款详情生命周期标签设计

日期：2026-08-11

## 目标

在收款详情页顶部，将收款操作已实际生效的结果以明显标签展示，并与“正式票据”或“临时票据”标签并排显示。

## 范围

仅调整收款详情页的状态展示。不新增接口，不改变收款更正、退款、作废、审批、权限或账务冲回规则。

## 标签规则

- 始终显示现有票据类型标签：正式票据或临时票据。
- `已更正`：收款记录存在已保存的更正原因，表示超级管理员的更正操作已经实际生效并保留审计记录。
- `部分退款`：收款状态为部分退款，表示退款审批已通过且实际冲回金额小于原收款金额。
- `已退款`：收款状态为全额退款，表示退款审批已通过且原收款已全额冲回。
- `已作废`：收款状态为已作废，表示作废审批已通过且账务冲回已执行。
- 待审批、已驳回、已取消的退款/作废申请不展示完成状态标签。
- 历史上已更正后再作废的收款可同时显示“已更正”和“已作废”，以保留真实业务轨迹。

## 实现方式

前端基于现有收款详情接口的权威字段计算展示标签：票据类型、收款状态和更正原因。标签计算封装为可单元测试的纯函数；详情页只负责渲染。

## 视觉与交互

标签放置在详情顶部票据类型标签所在行，使用与既有 Element Plus 标签一致的紧凑间距：

- 正式票据：成功色。
- 临时票据：警示色。
- 已更正：信息色。
- 部分退款：警示色。
- 已退款、已作废：危险色。

标签只说明已生效的结果，不替代申请记录、审批记录或账务明细。

## 测试

新增单元测试覆盖：正常正式票据、已更正、部分退款、全额退款、已作废、待审批申请不误显示，以及已更正和已作废并存的历史情形。前端完整单元测试与生产构建必须通过。
