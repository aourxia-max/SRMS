# 收款自动计数、合同状态、附件预览与状态中文化设计

日期：2026-08-21

状态：已实施并通过自动化验证

## 1. 背景与目标

本次变更解决四类易用性问题：收款登记需要重复输入金额、合同状态辨识度不足、合同图片附件只能下载、部分业务状态仍直接显示英文枚举值。

目标是在不改变冻结金额口径、合同生命周期、房态规则、权限模型和数据库结构的前提下，完善现有前端交互与显示。所有附件读取继续经过后端认证及合同访问权限校验。

## 2. 范围

### 2.1 收款登记金额自动统计

- 在“分配收款账期”中勾选账单后，将所选账单的未收金额合计写入“收款金额”。
- 取消勾选账单后立即重新计算。
- 计算结果采用现有金额精度，显示两位小数。
- 用户可以在账单选择完成后手动修改收款金额，用于部分收款等既有场景。
- 用户手动修改金额后，如果再次勾选或取消账单，系统重新自动统计并覆盖此前的手填金额；用户仍可在最后一次选择后再次修改。
- 开启优惠或减免时，继续沿用现有优惠后建议实收规则，不改变优惠归属账期、预收款、跳期分配和后端校验规则。
- 切换合同后，金额按新合同默认选中的首期未结账单重新计算。

### 2.2 合同状态彩色标签

合同列表和合同详情使用同一套中文状态标签和颜色，不新增状态：

| 后端状态 | 中文 | 视觉类型 |
| --- | --- | --- |
| `DRAFT` | 草稿 | 灰色 |
| `PENDING_START` | 待开始 | 橙色 |
| `ACTIVE` | 履约中 | 绿色 |
| `PENDING_CHECKOUT` | 待退租 | 橙红色 |
| `ENDED` | 已结束 | 灰蓝色 |
| `VOIDED` | 已作废 | 红色 |

- 合同列表中的状态列改为彩色标签。
- 合同详情头部展示当前合同状态标签。
- 颜色只用于提升辨识度，业务判断始终使用原始状态值。

### 2.3 合同附件图片在线预览

- 对浏览器可直接显示的图片类型提供“预览”操作，至少支持 JPEG、PNG、WebP 和 GIF。
- 点击预览后，通过现有带认证信息的附件读取请求获取二进制数据，再使用临时对象地址在弹窗中显示。
- 预览弹窗支持查看大图、缩放和关闭。
- 关闭弹窗、切换附件或组件卸载时释放临时对象地址，避免内存长期占用。
- 原有“下载”操作保留。
- PDF及其他非图片文件继续下载；HEIC 等浏览器通常无法直接显示的图片提示用户下载查看。
- 不暴露服务器存储路径，不创建绕过认证的公开附件地址，不降低现有后端权限校验。

### 2.4 状态全中文显示

- 合同详情“租金账单”的状态使用统一中文映射。
- 合同详情“收款记录”的状态使用统一中文映射。
- 房源管理“房态历史”的变更前状态、变更后状态使用统一中文映射。
- 优先复用现有 `status-labels` 工具；缺失映射时补齐集中映射及测试，页面不得各自复制一套状态名称。
- 接口和数据库仍保留英文枚举值，只转换展示文字。

## 3. 实现方案

采用最小改动方案：复用现有接口和集中状态映射，主要调整前端组件及测试。

### 3.1 收款金额状态管理

在收款登记页面增加一个明确的“按当前账单选择计算建议金额”过程。账单选择变化是自动计算触发点；金额输入框本身保持可编辑。优惠/减免变化继续使用现有建议金额逻辑，并与账单选择自动统计协调，避免产生循环监听或覆盖用户最后一次手工输入。

### 3.2 状态标签工具

在集中状态工具中增加合同状态对应的标签视觉类型函数，合同列表和合同详情共同调用。租金账单、收款记录及房态历史统一调用对应的中文名称函数。

### 3.3 附件预览

复用现有受保护的合同附件下载接口。前端服务层增加“读取附件 Blob”的能力，下载和预览共享同一读取过程：下载创建下载链接，预览创建临时对象地址。由于现有接口已经校验 JWT 和合同访问权限，不新建公开接口，也不需要数据库迁移。

## 4. 权限与安全

- 收款登记权限保持现状。
- 合同和房源的可见范围保持现状。
- 图片预览必须携带现有访问令牌并通过后端守卫和合同权限校验。
- 不把附件令牌写入 URL，不把附件内容持久化到浏览器存储。
- 不修改超级管理员、普通管理员和游客的既有权限。

## 5. 异常与边界处理

- 未选择账单时，自动金额为空或归零，并继续阻止提交空账期收款。
- 金额计算使用数值化及两位小数格式，避免字符串拼接。
- 附件加载失败时关闭加载状态并显示中文错误提示，下载操作仍可重试。
- 无权限、附件不存在或会话失效时，沿用全局接口错误与会话处理。
- 未识别的状态使用安全的中文兜底“未知状态”，开发环境可保留原值用于排查，但正式界面不直接展示英文枚举。

## 7. 验收与测试

### 7.1 收款登记

- 勾选一期账单，金额等于该期未收金额。
- 勾选多期账单，金额等于所有所选账单未收金额合计。
- 取消任意账单，金额同步减少。
- 手动修改金额后不立即回弹。
- 手动修改后再次改变账单选择，金额重新按选择结果计算。
- 切换合同后，账单和金额均按新合同重置。
- 多期账单结合优惠/减免仍可按现有规则提交。

### 7.2 合同状态

- 合同列表所有已知状态显示正确中文和颜色。
- 合同详情显示与列表一致的状态标签。
- 状态颜色不影响按钮权限和生命周期判断。

### 7.3 附件预览

- JPEG、PNG、WebP、GIF 图片可以在登录状态下预览。
- 关闭预览后释放对象地址。
- 非图片文件保留下载，不错误显示为图片。
- 无权限或失效会话不能读取附件。

### 7.4 中文化

- 合同详情租金账单无英文状态。
- 合同详情收款记录无英文状态。
- 房态历史变更前后状态均为中文。
