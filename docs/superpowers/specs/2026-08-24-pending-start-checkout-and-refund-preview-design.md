# 待开始合同退租与退款凭证预览设计

## 已确认业务规则

- 合同状态为“待开始”或“履行中”时，均可发起退租。
- 待开始合同按“未入住退租”处理；实际退租日期既可早于合同开始日期，也可晚于合同开始日期。
- 未入住退租仍走“发起退租、退租结算、押金退还确认、结束合同并释放房源”的完整流程。
- 退租结算允许录入欠租、维修、损坏、清洁和其他扣款；非欠租扣款继续执行现有验房依据校验。
- 结算编辑阶段由后端根据当前账单、押金、预收款和表单扣款项目返回实时预估：应退押金、应退预收款、合计应退、待补收金额。预估不写入财务账，超级管理员确认结算后才锁定正式金额。
- 取消退租工单时，合同和房态必须恢复为发起退租前的状态；待开始合同不得错误恢复为履行中。
- 退款凭证图片和 PDF 支持在线预览，同时保留下载；其他格式只提供下载。
- 权限与金额校验均由后端强制执行。

## 数据与兼容性

- 退租结算保存发起前合同状态，用于安全取消和状态恢复。
- 既有结算记录默认视为从“履行中”发起，保持历史行为不变。
- 不新增合同状态，不修改既有合同和历史财务数据。
