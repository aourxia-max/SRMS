# 退租结算重设计验收记录

日期：2026-08-11

## 范围

- 三步工作区：发起退租、退租结算、押金退还确认。
- 结算审批后合同和房源保持待退租；只有最终退款确认或零金额最终确认后才结束合同并更新房态。
- 退款总额固定为锁定的应退押金加应退预收款；审批时分别记入押金退款和预收款退款流水。
- 零金额退款无需上传凭证，仅超级管理员可最终确认。
- 后端详情接口返回退租页面所需的合同、房源、结算项目、退款摘要和两位小数金额字符串。

## 建议手工验收

1. 使用管理员账号发起一份测试专用的退租，确认合同和房源进入待退租。
2. 录入并提交结算；用超级管理员确认结算，确认合同和房源仍未结束。
3. 对有押金或预收款余额的结算，上传退款凭证并登记合并退款；超级管理员确认后核对两类退款流水、合同结束和房态历史。
4. 对三项锁定金额均为零的结算，确认页面不要求凭证且只有超级管理员能最终确认。
5. 使用普通管理员验证其不能执行结算确认或零金额最终确认。
## 复审修复（2026-08-11）

- 结算页现支持维护草稿：录入实际退房、交接、验房、退后房态、结算备注及欠租/验房扣款项目；草稿可提交，驳回后可退回草稿继续编辑。
- 正金额退款登记后，超级管理员可在同一页面确认退款并完成退租；页面展示已登记/已确认的退款状态。
- 零额最终确认、正金额退款确认均使用数据库条件更新领取结算状态；并发重复请求会被拒绝，不会重复写退款流水、结束合同或生成房态历史。
- 发起退租页在选择合同后展示只读财务快照：押金余额、当前欠租、预收款余额、未来账单数量。
